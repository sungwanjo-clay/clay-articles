The scoring model LOCKED AUG 11

One gate, two axes, one combined metric. Topic never penalizes a good skill — Effectiveness is scored relative to the best possible skill for that job; a loose "job tag" only scopes what's comparable, it is not a ranking bucket.

Gate · pass/fail
Verified

Safe · runs · never fabricates. Every published skill clears it.

Axis 1
Effectiveness

0–100, job-relative. Objective (precision/recall/coverage vs the golden set) where truth exists; else rubric. Instrument always labeled.

Axis 2
Cost

Clay credits + action-executions / record (median + p90). No tokens, no $.

Combined
Value

Effectiveness per unit cost — the "best + cheapest for this job" signal behind the tags.

Creator recognition (in the result payload, to make it feel special): Verified Best-for {job} Reference Founding Contributor

Timeline

Relative weeks (W1–W5) — they compress if we move faster. Striped bar = lead time we don't control (creators writing after we ask). The two long poles start in W1 because everything waits on them. Self-serve intake (D2) is gated on the gateway safety-block op + the Ploy form.
